# Polyglot DSA 🚀

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Active-brightgreen)](https://watashi.github.io/DSA)

A comprehensive, curated collection of Data Structures and Algorithms (DSA) implemented across multiple programming languages. This repository serves as a reference guide and learning resource for developers studying DSA in different paradigms, from low-level Assembly to high-level Python.

---

## 📂 Languages Covered

This project is organized by language, allowing you to explore implementations in:

- **Assembly (`asm/`)** - Low-level registers, stack frames, and manual memory access.
- **C (`c/`)** - Manual memory management, pointers, and structures.
- **C++ (`cpp/`)** - OOP paradigms, standard template library (STL), and templates.
- **Java (`java/`)** - Robust OOP, collections framework, and strict typing.
- **JavaScript (`js/`)** - Dynamic typing, prototypes, and functional array methods.
- **Python (`python/`)** - Clean syntax, built-in data types, and scripting-friendly implementations.
- **Zig (`zig/`)** - Modern systems programming, explicit memory management, and safety features.

## 🛠️ Getting Started

### Prerequisites

To compile or run the implementations, ensure you have the appropriate tools installed for each language:

| Language | Extension | Compiler / Runtime |
| :--- | :---: | :--- |
| **Assembly** | `.asm` | `nasm` / `yasm` & `ld` |
| **C** | `.c` | `gcc` / `clang` |
| **C++** | `.cpp` | `g++` / `clang++` |
| **Java** | `.java` | `JDK` (Java Development Kit) |
| **JavaScript** | `.js` | `Node.js` |
| **Python** | `.py` | `Python 3.x` |
| **Zig** | `.zig` | `Zig` compiler |

### Structure

Each language folder contains its own structure with implementations of:
1. **Data Structures**: Linked Lists, Stacks, Queues, Trees, Graphs, Hash Tables, Heaps.
2. **Algorithms**: Sorting, Searching, Dynamic Programming, Greedy Algorithms, Graph Traversals.
